# Programação Imperativa - PUCPR 📘

Este repositório contém diversos projetos e exercícios desenvolvidos na disciplina de **Programação Imperativa** da PUCPR. A estrutura está organizada por projetos e linguagens (C, C++ e Python), incluindo exercícios práticos, projetos integradores (PJBL) e bibliotecas auxiliares.

## 📂 Estrutura do Projeto


## 🚀 Como Executar

### 🐍 Scripts em Python
Requisitos: Python 3.x

```bash
cd PI2
python ex.py
```

### 🧱 C/C++
Para compilar os projetos em C ou C++:

```bash
# Exemplo para o PJBL2
cd PJBL2
gcc main.c -o main
./main
```
